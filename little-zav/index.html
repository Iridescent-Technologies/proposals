The widget · what it is

A companion that greets you before you ask.

Little Zav is a small, proactive card that lives on the learner's home screen. Every time you return it has something new and personal for you — a 20-second game, a nudge, a reflection — all drawn from your own learning. One delightful treat per visit.

It speaks first

Not a search box waiting for input — a companion that greets you by name, remembers your last session, and changes every login. It creates the "what's Little Zav got for me today?" pull.

Never punishes

Get it wrong and the card springs back and the mascot gives a little wobble — a cheeky nudge and a retry, never a hard red cross. It celebrates effort, not just correctness.

Walled garden

It reads your learning signals to stay relevant but writes nothing back into your records. No grades, no mastery scoring — pure encouragement. That clean boundary is what lets it run anywhere.

One playful character

A warmer, sillier little-sibling of the main Zavmo. The delight is in the copy, the motion, and the reward — never in clutter or emoji.

The widget · how it gets personal

Built from your data — different every single login.

Little Zav reads a bundle of signals about each learner and generates a fresh, fitting interaction. Nothing is fabricated: a brand-new account gets an honest "nothing yet", never a fake game.

What it reads

Recent lessons and topics, flow state, emotional archetype, streak, and preferred learning time — the same personalisation bundle the rest of the platform uses.

Freshness ledger

A "don't repeat" memory so you rarely see the same thing twice — plus the occasional deliberate callback: "remember this from Tuesday?"

Right time, right topic

It respects each learner's best time to learn and can space interactions along the forgetting curve, so a nudge lands when it'll actually stick.

For a Growth Engineering client, "your data" comes from that platform's learner-history API — so it's just as personal without any Zavmo account behind it.

The widget · connecting the content library

It knows the client's own content — and cites it.

Beyond each learner's history, Little Zav can draw on the organisation's whole content library. For Growth Engineering clients, the Growth Engineering LMS is a first-class connector — the same library that feeds builds like L'Oréal's "My Beauty Club".

Connect the library

Point Little Zav at the Growth Engineering LMS (or Go1, LinkedIn Learning, Google Drive, uploaded docs). It pulls the content in, chunks and embeds it.

Stays in sync

A live sync status shows last-synced, items pulled and errors. Turn a source on and it ingests; content that goes offline is auto-removed. Each item has a "Visible to Little Zav" toggle.

Answers with citations

Its knowledge chat answers only from the connected library and names the source — "Source: module / doc". Anything out of remit gets a playful deflection, never a wrong guess.

Two personalisation inputs, one companion: the learner's history (how they learn) + the client's library (what there is to learn). Little Zav sits in the middle and makes it fun.
The widget · the hero, quietly

Delight on the surface, insight underneath.

The Reflect family runs gentle, no-wrong-answer probes — growth mindset, confidence, innovation appetite, mood. To the learner it's a fun 10-second question. To the organisation it becomes anonymised, aggregate insight into how people think and feel.

Growth mindset index

Tracked as movement against each learner's onboarding baseline — are they trending more growth-oriented?

Confidence & innovation

Conversational confidence and curiosity/innovation signals, rolled up org-wide as a spectrum and a trend.

Sentiment & mood

A rolling sentiment line and this-week's mood distribution — an early read on how a cohort is doing.

Feeds both ways

Every answer also personalises that learner's own next interaction — a fair exchange, not extraction.

Insight, not surveillance. Org analytics are aggregate and anonymised, there are no "wrong" answers, sensitive dimensions carry a consent flag, and the whole family can be switched off in one click.

Deployment · switching it on

One login, one handshake, no second sign-in.

The client portal already knows who the learner is. Little Zav trusts that with a signed, short-lived token — so the learner never logs in twice.

1
Client mints a token

The client's backend issues a short-lived RS256 JWT — learner id, tenant, role — signed with that tenant's private key.

2
Portal hands it to the widget

The embedded widget receives the token via a postMessage handshake on load.

3
Little Zav verifies & resolves

It checks the token against that tenant's registered public key and resolves the learner. In and playing — no second login.

Per-tenant keys: a token from tenant A is rejected by tenant B. The role claim gates the admin surface.
Deployment · the four-part contract

Four things any host implements. Zavmo built them first.

Little Zav is a product, not a feature — so every host, Zavmo included, integrates the same way. Zavmo is tenant #1: the reference integration and the template for the client SDK.

01
Provision the tenant

Register the SSO public key, allowed embed origins, branding, and content / history endpoints.

02
Mint an SSO token

One backend endpoint returns a signed short-lived token for a logged-in learner. A thin SDK ships with it.

03
Embed the widget

Drop a <script> / <iframe> on the learner portal (and admin), pass the token.

04
Provide content & history

A small read API: list content items and return a learner's history. GE wraps the Growth Engineering LMS.

Little Zav provides the hosted service, database, widget + admin bundles, the API, tenant config, SSO verification and xAPI. The client provides four small pieces — and it's live.
